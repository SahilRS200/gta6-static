GTA 6 unlocked in India at **12:00 AM IST**, but not every PS5 got the memo. If the game tile still shows a padlock, or the game refuses to start, work through these steps in order. **Don't delete the 212 GB install first.** A licence or account problem won't be fixed by downloading the game again.

## 1. Are you on the right account?

The game unlocks only for the PSN account that bought it, or the account that redeemed the code. PlayStation India's GTA VI support page asks you to confirm you're signed in to the **pre-order account** before anything else ([PlayStation India](https://www.playstation.com/en-in/support/games/gta-vi-support/)). If a family member bought it, they need to turn on **Console Sharing and Offline Play** from their own account: *Settings > Users and Accounts > Other > Console Sharing and Offline Play > Enable*.

## 2. Restore licences

Still locked on the right account? Go to *Settings > Users and Accounts > Other > Restore Licenses*. Sportskeeda lists this as the fix for account and licence errors such as **CE-109245-1, NP-104291-7 and CE-105638-3** ([Sportskeeda](https://tech.sportskeeda.com/gaming-news/all-gta-6-error-codes-ps5-possible-fixes)).

## 3. Install the PS5 system update

Sony says system software **26.07-14.23.00** is needed to play. Check *Settings > System > System Software > System Software Update and Settings*. [Which version you need →](/news/gta-6-ps5-system-update-required/)

## 4. Bought the Blinkit, Zepto or store box? Redeem the code

The India box is **Code-in-Box**: no disc, just a download code. Until you redeem it (avatar menu > **Redeem Code**), the PS5 doesn't know you own the game. If the code is missing or unreadable, PlayStation says to contact the retailer ([PlayStation India](https://www.playstation.com/en-in/support/games/gta-vi-support/)). [About the code-in-box edition →](/news/blinkit-zepto-gta-6-delivery-10-minutes-india/)

## 5. "Services are busy"? Wait it out

If PSN sign-in itself is failing, the steps above won't help yet. Check status.playstation.com and retry in a few minutes. [Launch-night PSN errors →](/news/gta-6-psn-sign-in-error-services-busy-reddit-down/)

## 6. Download stuck?

Open **Downloads/Uploads**, pause and resume. If that fails, cancel the download, go back to the Game Library and turn auto-download on again. Make sure you have **212 GB free** under *Settings > Storage* ([PlayStation India](https://www.playstation.com/en-in/support/games/gta-vi-support/)).

## Who to contact

PlayStation's page splits it: **PlayStation Support** for launch, download, code and refund problems; **Rockstar Support** for bugs and gameplay issues.
